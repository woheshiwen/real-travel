# 真程 Real Travel

结合**实况天气**与**出发地交通**的 AI 动态行程系统，并面向长期做成：

1. **大家真正用得上、信得过的实用系统**（数据可核对、行程可改版）
2. **可分享快乐的交互平台**（足迹广场：亲历喜悦与避坑沉淀）

## 旧代码包还在吗？

在。原始站点压缩包仍保留在 `main` 分支：

- 文件：[`www.lvtushijie.cn.rar`](https://github.com/woheshiwen/real-travel/blob/main/www.lvtushijie.cn.rar)
- 对应旧项目「旅兔视界」（ThinkPHP + uni-app H5）

新系统**借鉴其多端架构思路**（用户端 / 运营 / API），但产品方向已转向「实况行程 + 社区足迹」，不复刻旧旅拍业务。

## 长期方向

- 接入实时天气、交通动态、预约余票
- 账号体系与可信内容治理（亲历认证、实况对照）
- 行程结束后一键分享到足迹广场
- 运营后台与开放数据源（延续旧站多应用架构经验）
